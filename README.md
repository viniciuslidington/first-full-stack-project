# Projeto Full Stack com Prisma e Vite

Este é um projeto full stack simples que implementa uma página de cadastro de usuários. O backend foi desenvolvido com Node.js utilizando Prisma como ORM, enquanto o frontend foi criado com React e Vite.

## Tecnologias Utilizadas

### Backend

- Node.js
- Express
- Prisma ORM
- MongoDB

### Frontend

- React
- Vite
- Axios

### Endpoints da API 

* GET /users
* POST /users
* PUT /users/id
* DELETE /users/id
